# 🚀 ME7 Rolling Anti-Lag CMD V2

A modern **Rolling Anti-Lag installer and configurator** for **Bosch ME7 / ME7.5 ECUs**, running entirely from the Windows Command Prompt (CMD).

This project was created as an improved version of the original Rolling Anti-Lag installer that has been circulating within the ME7 community for many years.

Unlike the original release, this version is capable of detecting an existing Launch Control installation and automatically installing Rolling Anti-Lag in a separate code cave with its own independent configuration area. Instead of aborting the installation, the program automatically creates a chained execution path:

**Hook → Rolling Anti-Lag → Launch Control**

This allows both features to coexist without overwriting each other.

---

# ✨ Features

## 🔥 Interactive Configuration

After detecting or installing Rolling Anti-Lag, the program automatically enters **Configuration Mode**.

You can configure:

* 🔥 Rolling RPM
* ⚡ Throttle Threshold
* 🎮 Activation Trigger

Supported activation triggers:

* Cruise Control **SET**
* Cruise Control **RES**
* Brake

All configuration is performed directly from the Windows Command Prompt.

No HEX editor or manual BIN modification is required.

---

## 🔍 Automatic Detection

The program automatically detects:

* Existing Rolling Anti-Lag installation
* Existing Launch Control installation

If Rolling Anti-Lag is already installed, the program immediately switches to **Configuration Mode** instead of reinstalling the feature.

If Launch Control is detected, the installer automatically:

* Locates a new free code cave
* Allocates a separate Rolling configuration block
* Preserves the existing Launch Control installation
* Creates an execution chain:

```text
Hook
  ↓
Rolling Anti-Lag
  ↓
Launch Control
```

No existing Launch Control code or configuration is overwritten.

---

## 🧠 Automatic Memory Allocation

Unlike the original installer, this version does not rely on fixed installation addresses.

When Launch Control is already present, the installer automatically searches for:

* A free code cave for Rolling Anti-Lag
* A separate configuration area
* Available memory without conflicting with existing patches

This allows Launch Control and Rolling Anti-Lag to coexist safely inside the same BIN file.

---

## ✅ Automatic Verification

Every configuration change is verified before the modified BIN file is saved.

The program verifies:

* Rolling Anti-Lag installation
* Launch Control compatibility
* Hook chaining
* Configuration data
* Output BIN generation

---

## 🛡 Safe File Handling

The original BIN file is never overwritten.

Example:

```text
dump.bin
      ↓
dump_mod.bin
```

Your original BIN file always remains untouched.

---

## 🔧 Checksum

The current version does **not** perform automatic checksum correction.

After configuring Rolling Anti-Lag, the checksum must be corrected manually using **me7sum.exe**.

Example:

```cmd
me7sum.exe dump_mod.bin dump_csok.bin
```

After this step, **dump_csok.bin** is ready to be flashed to the ECU.


---

# 📄 Creating the ECU File

The program requires an **.ecu** file containing ECU information used during Rolling Anti-Lag installation and configuration.

This file is automatically generated by **ME7Info.exe**.

Example:

```cmd
ME7Info.exe dump.bin
```

After execution, the following file will be created:

```text
dump.ecu
```

At this point you should have:

```text
dump.bin
dump.ecu
```

---

# 🚀 Running Rolling V2

After generating the **.ecu** file, Rolling V2 can be started.

Example:

```cmd
Rolling_V2.exe dump.bin dump.ecu
```

The program will automatically:

* Detect Rolling Anti-Lag
* Detect existing Launch Control
* Install Rolling if necessary
* Automatically chain Rolling with Launch Control
* Enter Configuration Mode
* Verify all settings
* Save the modified BIN file

Output example:

```text
dump.bin
      ↓
dump_mod.bin
```

---

# 🔧 Correcting the Checksum

After Rolling V2 finishes, correct the checksum manually.

Example:

```cmd
me7sum.exe dump_mod.bin dump_csok.bin
```

The final file ready for flashing is:

```text
dump_csok.bin
```
